# To-Do List Console App

Небольшое консольное Java-приложение для управления списком задач.

## Что умеет программа

- добавлять новую задачу;
- показывать все задачи в структурированном виде;
- менять статус задачи (`NEW`, `IN_PROGRESS`, `DONE`);
- удалять задачу по `id`;
- автоматически загружать задачи из файла при запуске;
- автоматически сохранять задачи в файл `tasks.txt` после изменений.

## Структура проекта

- `src/com/aveelon/todo/Main.java` — точка входа;
- `src/com/aveelon/todo/ui/ConsoleApp.java` — консольное меню и взаимодействие с пользователем;
- `src/com/aveelon/todo/model/Task.java` — модель задачи;
- `src/com/aveelon/todo/model/TaskStatus.java` — enum со статусами задачи;
- `src/com/aveelon/todo/service/TaskManager.java` — бизнес-логика управления задачами;
- `src/com/aveelon/todo/repository/TaskRepository.java` — чтение и сохранение задач в файл.

## Как запустить

1. Открыть терминал в корне проекта.
2. Скомпилировать проект:

```bash
javac -d out src\com\aveelon\todo\Main.java src\com\aveelon\todo\model\*.java src\com\aveelon\todo\repository\*.java src\com\aveelon\todo\service\*.java src\com\aveelon\todo\ui\*.java
```

3. Запустить приложение:

```bash
java -cp out com.aveelon.todo.Main
```

## Формат хранения

Задачи сохраняются в файл `tasks.txt` в текстовом формате:

```text
id|название|статус
```

Пример:

```text
1|Купить продукты|NEW
2|Подготовить отчёт|DONE
```

## Ответы по OOP

OOP — это подход к программированию, в котором программа строится вокруг объектов, объединяющих данные и поведение.

- Инкапсуляция — скрывает внутреннюю реализацию объекта и даёт доступ к данным через контролируемый интерфейс.
- Наследование — позволяет создавать новый класс на основе существующего и переиспользовать его поведение.
- Полиморфизм — позволяет работать с объектами разных классов через единый интерфейс.
- Абстракция — помогает выделить только важные характеристики объекта и скрыть лишние детали.
